# Franks Monster Hub

eu gostaria de criar um painel de admin para o meu sistema com menu lateral. Este sistema se chama Frank porque será um sistema que conversará com vários outros, terá diversos componentes diferentes, assuntos diferentes, como se fosse um Frankstein mesmo. A ideia é que este aplicativo tenha uma "temática" de halloween, com o menu lateral separado da página de conteúdo com algo que lembre um arame farpado, os icones de menu poderia ser personagens do halloween ou familia adams, com caveiras, teias de areia, caveira, frank, e outras coisas.
